# Roar Tourism Tour Packages & Pricing Catalog

Use this document to customize the tours, pricing, seasons, and timings that the AI agent offers to customers. The agent reads this file dynamically on every message, so changes here will instantly update the agent's knowledge and quoting rules.

## Camp & Safari Locations
*   **Safari Location**: Lahbab Desert (famous Red Dunes of Dubai).
*   **Camp Location**: Roar Tourism Al Awir Camp / Desert Staging Camp, Dubai.

## Seasonal Pricing Rules
*   **Peak Season**: October to April (inclusive)
*   **Off-Peak Season**: May to September (inclusive)
*   **Agent Logic**: The agent must identify the customer's desired tour date. If the tour date falls between October and April, the agent must quote the **Peak Rate**. If it falls between May and September, the agent must quote the **Off-Peak Rate**. If the date is not specified yet, the agent can quote both or ask for the date first.
